ANGEL GARG — FULL PORTFOLIO WEBSITE

Files included:
- index.html
- styles.css
- script.js
- assets/angel-profile.png (enhanced portfolio portrait)
- assets/angel-profile-placeholder.svg (original placeholder asset)

HOW TO RUN
1. Extract the complete ZIP while keeping the folder structure intact.
2. Open index.html in a browser, or upload the complete folder to Firebase Hosting / GitHub Pages.
3. The enhanced portrait is already connected in index.html at assets/angel-profile.png. Replace that file if you want to use another portrait.

PERFORMANCE VIDEO
The video is embedded directly in the page. It is set to play only the selected section from 12:35 to 15:35. The YouTube IFrame API seeks to the beginning and pauses at the end of the excerpt. An internet connection is required for YouTube playback.

Do not upload only index.html: keep styles.css, script.js and the assets folder alongside it.
